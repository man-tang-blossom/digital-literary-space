# 文学内容收录流程

## 1. 随手收集

任何句子、词表、图片灵感、作者故事或现实风景先放入 `content/inbox/`。只需要保留原始文字、发现地点或链接，以及为什么喜欢它。

## 2. 判断内容类型

- 完整诗文：作品
- 作者相关轶事：作者故事
- 金、玉、山、水等词群：意象
- 江湖再见、风雪行人等策划：主题选集
- 朝代文学“吃法”：文心百味文章
- 同一件事的不同表达：辞语新生
- 现实花海、步道与城市风景：人间采风

一份材料可以同时关联多个类型，但只能有一个主要归档位置。

## 3. 核验

优先检查：作者、作品名、原句、时代、版本、是否为现代改写。古籍与诗词优先使用权威古籍库、正式出版物或可靠学术资料；旅游与现实地点信息在发布前检查最新状态。

## 4. 编辑

- 普通作品：60–120 字赏析。
- 重要作品：可增加结构、典故、版本差异与延伸阅读。
- 作者故事：100–250 字，注明史实、笔记轶闻或传说。
- 意象词：删去出处不明、意义重复、过于晦涩且无展示价值的条目。
- 网络流传文字：保留原链接和作者信息；无法确认时不标原创。

## 5. 建立关系

至少连接一个作者、一个主题或一个意象。精选内容再加入主题选集，使用户可以从一个句子走向另一篇作品。

## 6. 发布检查

- 原文与赏析是否分开？
- 出处是否明确？
- 现代改写是否标注？
- 作者故事的可信程度是否说明？
- 赏析是否简洁、避免套话？
- 是否已经建立必要关系？
