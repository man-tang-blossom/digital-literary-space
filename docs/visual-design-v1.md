# 《数字文学空间视觉规范 V1.0》

> 状态：视觉方向初稿，待确认后进入网页原型阶段  
> 核心参考：用户原创演示文稿《绝美PPT》24 页  
> 本规范提取其审美逻辑，不复制具体页面、背景或版式。

## 0. 视觉判断摘要

这份 PPT 的核心不是通常意义上的“古风”，而是用现代平面秩序容纳东方山水经验：画面远、淡、静，文字少而有呼吸，图像像被陈列的画卷，青蓝只负责牵引视线，不负责制造喧闹。

整体气质可以落在以下坐标上：

| 维度 | 判断 |
| --- | --- |
| 安静 / 热烈 | 明显偏安静，情绪通过远景与渐层缓慢释放 |
| 东方 / 现代 | 东方审美为精神内核，现代编辑设计为组织方式 |
| 简约 / 丰富 | 版式简约，图像与文化语义丰富 |
| 理性 / 感性 | 骨架理性、表情感性；网格清楚但不显机械 |
| 学术 / 艺术 | 具有文化讲述的学术底色，最终呈现更偏艺术散文 |
| 清透 / 厚重 | 清透为主，借古画、器物与墨色提供少量历史重量 |

**核心关键词：** 空濛、疏朗、含蓄、书卷、远游、层叠、清润、留白、静观、古今相接。

需要保留的是“远近、虚实、疏密”的关系，而不是山水背景本身。网站不能处处铺山水，也不能把古典等同于纹样、卷轴、印章和仿旧纸。

## 1. Design Philosophy｜设计理念

### 1.1 一页不是一张海报，而是一段可停留的路

页面应给人“进入—停留—发现—转向”的感受。首页负责打开空间，阅读页负责安静承载，关系网络负责引向别处。任何视觉效果都要服务于这条漫游路径。

### 1.2 以白为纸，以雾为界，以青为引

- 白色承载阅读，是主要空间。
- 雾感负责连接内容区，而不是遮挡内容。
- 青蓝标记路径、关联和当前状态。
- 墨色承担正文与历史重量。

### 1.3 让关系出现，不让界面喧哗

组件边界尽量依靠留白、对齐、细线和轻微明度差表达。避免大量卡片、粗边框、高饱和按钮和持续发光的“宇宙特效”。“文学星空”应是一种关系体验，不是一张科幻背景图。

### 1.4 古典气质通过节奏生成

古典感主要来自字体、行距、纵横转换、画面比例、留白和叙事节奏。纹样、印章、宣纸肌理只能偶尔出现，并且必须有内容依据。

## 2. Color System｜颜色系统

### 2.1 核心色板

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| `Background / Paper` | `#F7F8F5` | 全站主背景、长文阅读底色 |
| `Surface / Clear` | `#FFFFFF` | 图片留白、浮层、需要更清晰分界的局部 |
| `Primary / Mountain Blue` | `#6391A9` | 主链接、关系连线、当前栏目、关键数字 |
| `Secondary / Mist Blue` | `#BAD1D7` | 大面积淡层、分区背景、图表次级关系 |
| `Atmosphere / Pale Cyan` | `#E4EEF0` | 雾层、悬停底色、阅读区过渡 |
| `Ink / Main Text` | `#283033` | 正文与主要标题，避免纯黑的生硬 |
| `Ink / Secondary` | `#6E747A` | 元数据、说明、非核心信息 |
| `Line / Hairline` | `#D8DEDF` | 分隔线、输入框边界、网络弱连接 |
| `Accent / Seal` | `#A65F4B` | 收藏、重点标记、印记；仅作极少量点睛 |
| `Accent / Aged Gold` | `#A88B5B` | 史料、版本、年代提示；谨慎使用 |

其中 `#6391A9`、`#BAD1D7`、`#5487A6` 等青蓝来自 PPT 中反复出现的显式颜色；网页色板在此基础上补充了更适合屏幕正文的纸白与墨色。

### 2.2 色彩比例

- 纸白与透明留白：约 **70–76%**。
- 雾青与低对比背景层：约 **14–20%**。
- 墨色文字与深色图像：约 **8–12%**。
- 主青、朱砂、旧金等强调色合计：不超过 **3%**。

### 2.3 使用边界

- 可大面积使用：`Paper`、`Clear`、`Pale Cyan`、低透明度 `Mist Blue`。
- 可中等面积使用：`Mountain Blue`，但应降低透明度或只出现在图像层、关系网络与章节入口。
- 只能点缀：`Seal`、`Aged Gold`。同一屏通常只出现一种暖色强调。
- 正文不得使用低对比青灰；长文应保持至少清晰可读的墨色对比。
- 禁止用纯黑大底、高饱和蓝紫渐变或霓虹色来表达“星空”。

### 2.4 渐变与透明

允许的渐变是“雾化过渡”，而非装饰性彩虹：

```text
Mist Fade: rgba(228, 238, 240, 0) → rgba(186, 209, 215, 0.58)
Paper Veil: rgba(247, 248, 245, 0.92) → rgba(247, 248, 245, 0.64)
```

渐变跨度应长，边界不可明显。正文背后如有图片，必须加足够纸白遮罩保证阅读。

## 3. Typography System｜字体系统

### 3.1 从 PPT 提取的文字气质

PPT 使用了康熙字典体、楷体、方正清刻本悦宋简体、微软雅黑 Light、Times New Roman 与 Lucida Calligraphy。其隐藏规律是：

- 大标题倾向书写感、宋刻感或斜体，负责情绪。
- 正文采用稳定的宋体或衬线体，负责叙述。
- 超大数字以极轻颜色出现，作为章节空间而非信息主体。
- 正文以常规字重为主，强调依靠颜色和位置，不依赖粗黑。
- 中文竖排只在诗句、题记和图像旁出现，不用于长文导航。

### 3.2 网站推荐字体组合

**中文阅读主字体：** `Noto Serif SC` / 思源宋体。用于正文、作品标题和作者信息，结构稳定，适合长文与多字重排版。

**中文诗性展示字体：** `LXGW WenKai` / 霞鹜文楷。用于首页短句、诗词题记、少量栏目引语。它接近 PPT 的楷体气质，但不可用于大段正文。

**英文展示与混排：** `EB Garamond`。用于英文项目名、拉丁字母标题、年份与题记；其古典衬线比默认 Times 更温润。

**界面辅助字体：** `Noto Sans SC` / 思源黑体。仅用于按钮、筛选、表单与需要快速辨认的微型文字。

推荐字体均有明确的开放字体项目来源；正式接入时应将字体文件自托管、保留许可证，并针对中文大字体文件做子集化。不要直接沿用 PPT 中授权范围未确认的商业字体。

### 3.3 字体角色规范

| 角色 | 字体 | 建议字号 | 字重 | 行高 / 字距 |
| --- | --- | --- | --- | --- |
| 首页标题 | 霞鹜文楷 + EB Garamond | `clamp(52px, 8vw, 112px)` | 400 | 1.05 / 中文 `0.08em` |
| 栏目标题 | 思源宋体 | `clamp(32px, 4vw, 56px)` | 500 | 1.2 / `0.04em` |
| 作品标题 | 思源宋体 | `clamp(30px, 3.5vw, 48px)` | 500 | 1.25 / `0.06em` |
| 诗词原文 | 思源宋体；短题记可用文楷 | 24–32px | 400 | 1.9–2.2 / `0.08em` |
| 散文正文 | 思源宋体 | 18–20px | 400 | 1.9–2.05 / `0.02em` |
| 注释文字 | 思源宋体 | 14–16px | 400 | 1.7–1.85 / `0.01em` |
| 标签文字 | 思源黑体 | 12–14px | 400–500 | 1.4 / `0.08em` |
| 日期文字 | EB Garamond + 思源宋体 | 13–15px | 400 | 1.4 / `0.08em` |

### 3.4 排版原则

- 长文默认左对齐，不使用两端强制对齐。
- 中文正文每行以约 32–40 个汉字为舒适上限。
- 标题与正文避免同时使用强书法字体；每个视口只保留一个情绪焦点。
- 中英文混排时，英文与数字使用 EB Garamond；标点与中文正文保持同一中文字体，避免字面跳动。
- 大段文字不使用浅蓝；青蓝只标记链接、关键词或引用来源。
- 竖排是特殊叙事手段：适合诗句、题签、章节序，不适合导航、正文和操作说明。

## 4. Layout System｜布局系统

### 4.1 PPT 为什么看起来舒服

它反复使用“半幅图景 + 半幅纸面”“大面积空白 + 小块内容”“远景底层 + 明确文本层”三种结构。页面通常只有一个视觉中心；图片与文字不是相互争夺，而是各占一段呼吸。纵向文字和超大章节数字进一步拉长了阅读时间。

网站应继承这种疏密节奏，而不是继承固定的 50/50 分屏。

### 4.2 网格与宽度

- 全站内容最大宽度：`1280px`。
- 常规页面网格：桌面端 12 栏，栏间距 `24px`。
- 长文阅读宽度：`680–760px`，推荐默认 `720px`。
- 注释侧栏：`240–300px`，与正文间隔至少 `48px`。
- 全宽视觉段最大内容宽度：`1440px`，超出部分由背景留白吸收。
- 页面左右边距：桌面 `clamp(48px, 6vw, 112px)`；平板 `32px`；手机 `20px`。

### 4.3 垂直节奏

采用 8px 基础单位，但常用间距应偏舒展：

| 场景 | 间距 |
| --- | --- |
| 页面顶部至首标题 | 96–160px |
| 标题与副标题 | 20–32px |
| 标题与正文首段 | 40–64px |
| 正文段落 | 20–28px |
| 章节之间 | 96–160px |
| 卡片之间 | 24–40px |
| 图像与图注 | 12–16px |
| 图像与相邻正文 | 40–72px |

### 4.4 图文比例与阅读顺序

- 首页可使用 60% 氛围、40% 文字与入口，但首屏只能有一个主入口。
- 作品页以文字为主，图片不应频繁打断正文；每 3–5 个阅读屏再出现一处视觉停顿更合适。
- 作者页可采用 4:8 或 5:7 的图文结构，避免头像式资料卡成为全部视觉中心。
- 文学星云允许更高信息密度，但外围必须保留安静区域，并给用户明确的返回阅读路径。
- 桌面端可交替左右构图；移动端统一回归单列，先标题、后图像、再正文。

### 4.5 图片比例

- 横向画卷、山河：`16:9`、`3:2` 或超宽 `2.4:1`。
- 人物、器物、植物：`4:5` 或 `3:4`。
- 文献局部：保留原比例，以纸白托底，不强行裁满。
- 图片不默认圆角；需要弱化边缘时使用 0–4px 极小圆角，而非应用卡片式大圆角。

## 5. Image System｜图片系统

### 5.1 从 PPT 提取的规律

- 山景常作为被淡化的空间底层，具有远近层次而非明确叙事焦点。
- 古画通常完整或接近完整地陈列，四周留白，像观看册页。
- 食物、器物图片使用近距离静物构图，依靠叶片、陶瓷、木色等自然材质建立触感。
- 图片与文字并置多于文字压图；文字覆盖图片时，会通过大面积白雾层隔开。
- 分隔主要依靠细线、色块与透明层，几乎不依赖明显投影。

### 5.2 网站图片方向

未来图片应优先选择：

- 有空气透视、薄雾、自然光和层次的山水与空间摄影；
- 保留纸张、绢本、墨迹和岁月痕迹的高清文献图像；
- 构图克制、背景简洁、色彩偏低饱和的草木与器物静物；
- 可见尺度与环境关系的人文场景，而非泛化的“古装氛围照”。

图片色调以雾青、灰绿、纸白、墨褐为主。暖色应来自真实对象，如印泥、木器、灯火、花果，而不是统一滤镜。

### 5.3 裁切与处理

- 先尊重原作构图，再适配页面；古画和文献不得为填满容器而粗暴裁切。
- 摄影图允许 `object-fit: cover`，但人物视线、题跋、印章和核心物象必须完整。
- 背景图饱和度建议降低 10–25%，对比降低 8–18%，并使用纸白遮罩。
- 禁止重度颗粒、仿旧裂纹、卷轴边框、烫金边和厚重暗角。
- 图片版权、出处、年代与替代文本必须进入内容数据，而不是只写在页面角落。

### 5.4 线条、阴影与材质

- 分隔线：1px，使用 `Line / Hairline`。
- 阴影：默认不用；浮层最多使用 `0 18px 60px rgba(40,48,51,.08)`。
- 透明层：允许，用于制造“隔着雾看”的深度，但不能降低正文可读性。
- 纸张纹理：只允许非常轻微、近乎不可察觉的噪点；阅读页应保持干净。

## 6. Component Style｜组件风格

### 导航

导航像书的目录，不像应用控制台。默认无底板，使用文字、细线和当前位置标记；移动端菜单展开后仍保留大量留白。

### 作品入口

作品入口以“题名 + 作者 + 一句引文或一个意象”为最小单位。默认无厚边框、无大圆角、无常驻阴影。悬停时可出现淡雾底色、细线延展或关联词浮现。

### 作者入口

不做标准头像卡。可使用画作局部、署名、时代与代表意象形成纵向组合；照片或画像是资料，不是社交头像。

### 标签与分类

标签应像索引词或书页眉注，使用小字号、较宽字距和细线边界。避免彩色胶囊堆叠。同一页面标签不超过两级视觉权重。

### 引文与注释

引文通过缩进、留白、竖排题签或左侧细线表达；不使用巨大引号图标。注释采用侧注优先，窄屏转为正文后的可展开脚注。

### 文学星云节点

- 节点以文字为主，圆点只是定位，不做发光球体。
- 节点大小表达关系密度，但最大与最小比例不宜超过 2.5 倍。
- 强关系使用 `Mountain Blue`，弱关系使用 `Hairline`；暖色只标识用户当前选择或私人文字。
- 聚焦一个节点时，其余关系淡出至 15–30% 不透明度，避免整屏噪声。

### 按钮与操作

主要操作使用文字加细线或小面积青蓝，不使用高亮渐变大按钮。按钮文案应带有文学空间感但仍清楚，例如“进入星云”“沿此意象漫游”，不能牺牲可理解性。

## 7. Animation Style｜动画风格

动画关键词：**缓入、浮现、层叠、停驻、回应**。

- 页面进入：内容以 16–28px 的微小位移和透明度变化出现，时长 500–800ms。
- 文字：按块出现，不逐字打字；诗句可以分行渐显，行间延迟 80–140ms。
- 图片：允许非常缓慢的 1.00 → 1.025 比例变化，持续 8–16 秒，仅用于封面氛围。
- 星云：节点移动应具有阻尼感，用户停止操作后 300–500ms 内安定，不持续漂浮。
- 悬停：150–240ms，主要改变颜色、细线长度和明度；不使用弹跳。
- 页面转场：优先淡入淡出和层次错位，不模拟翻书特效。
- 滚动视差：最大位移控制在视口高度的 3–5%，防止眩晕。
- 必须响应 `prefers-reduced-motion`，关闭自动缩放、视差和长距离位移。

原则：动画应像雾散、水纹与目光转移，不像粒子烟花。任何持续运动都必须能停止。

## 8. 三个想象问题

### 1. 如果这个 PPT 是一本书，它是什么类型的书？

它像一本当代编辑设计的宋人生活美学随笔集：不是严肃厚重的考据专著，也不是堆砌古典符号的画册，而是以山水、器物、诗句和日常生活互相映照的轻学术读物。纸面很白，图版很静，章节之间允许读者停下来。

### 2. 如果它是一座空间，它像什么地方？

它像山脚临水的一间现代文人书斋，兼有小型美术馆的秩序。窗外是远山，室内有白墙、长案、册页和少量器物；人与展品之间距离宽松，转过一道半透明屏风才进入下一段内容。它不宏伟，却有可独处、可回望、可绕行的深度。

### 3. 如何把这种感觉转化成一个数字文学空间？

让首页成为“远望”，阅读页成为“入室”，关系网络成为“推窗”。用户先被一个句子或意象吸引，进入一篇安静、清晰的作品；阅读途中，作者、意象、时代和其他作品像侧注一样轻轻显现；读完后，关系网络不是要求用户操作的图表，而是一片可以继续走入的远景。空间感来自内容之间的距离与连接，而不是来自铺满屏幕的宇宙视觉。

## 9. V1.0 验收准则

未来任何页面原型都应通过以下检查：

1. 移除所有装饰图片后，页面是否仍有清楚而舒展的阅读秩序？
2. 首屏是否只有一个明确视觉中心和一个主要进入动作？
3. 青蓝是否在引导关系，而不是大面积制造风格？
4. 暖色点缀是否少于整体视觉面积的 3%？
5. 长文宽度、字号、行高和对比度是否适合连续阅读？
6. 图片是否尊重原作构图、版权和出处？
7. 动画是否可以停止，并在减少动态模式下保持完整体验？
8. 页面是否表达“可漫游的文学关系”，而不只是“古风好看”？

若其中两项以上不满足，应先修正信息层级与节奏，不应继续添加装饰。
